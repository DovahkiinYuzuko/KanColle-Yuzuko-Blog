## 自作ツール

完全に私用です。都合上GitHub上に置いてますが使用はおすすめしません。

### kcyaml
デッキビルダー方式のjsonをyamlに変換するスクリプト。ついでに画像の作成も可能です（[`gkcoi`](https://github.com/Nishisonic/gkcoi/)使用）。他所様からIDなどの情報を取得してるのでDBの用意などは不要です。

> [!NOTE]
> タグ`kcyaml/v*`を打ってプッシュするとReleasesにkcyamlのzipが作成されます。

### kctemp
テンプレートのMDファイルから要素を選択して新しく雛形を作成するツール。

> [!NOTE]
> タグ`kctemp/v*`を打ってプッシュするとReleasesにkctempのzipが作成されます。
